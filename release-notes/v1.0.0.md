# Chatward v1.0.0

The first full release. This is built from the `main` branch (merge commit 6bbe5be). It covers everything since v0.2.0 (about 80 changes).

The installer is not code-signed, so Windows may show a "Windows protected your PC" warning. Click "More info", then "Run anyway".

## New things you'll notice

**A new look**
- New default layout: tabs along the top, with split view and tabs you can pop out into their own window.
- Pick a skin from a dropdown: Original, Lebserver (retro, the default), Retro ASCII and LCARS (a Star Trek style console with its own layout).
- Every skin now has a light and a dark version, and its own set of icons.
- The app draws its own title bar, so the window matches the skin.
- New app icon.

**Chat**
- @mentions with a member picker, a ping sound and a switch to silence them all. Mentions show as pills.
- Search chat by word, by person, or by pictures and videos.
- Bigger picture and GIF previews in chat. The chat stays scrolled to the bottom while pictures load.
- Preview pictures in the message box before you send them.
- Click any picture or GIF to open it in a viewer. You can zoom and drag, and profile pictures and banners open there too.
- Right-click a picture or GIF to copy it.
- Deleting a message asks first, with a "don't ask again" box.
- Emoji-only messages show big.

**Voice and video**
- Participant tiles fill the voice screen. There's a connection signal icon in the call header.
- Screen share defaults to 4K and fits the whole share on screen.

**Watch parties and media**
- Watch party queue: add YouTube links, mp4 links or movies from the Jellyfin library, with Skip, Play now and auto-advance. Play, pause and seeking stay in sync.
- Jellyfin library browser, so you can watch movies and episodes together.
- Vault: a shared photo and video gallery for the group.
- GIF library: a shared GIF tab, save GIFs from chat, and a GIF maker.

**Spotify**
- Connect Spotify in Settings > Privacy to show "Listening to ..." under your name.
- Join Jam cards for Spotify links, album cover and song progress on profile cards, and Listen Along invites in chat.
- If you connected Spotify earlier, reconnect once in Settings > Privacy so Listen Along works.

**Simpler accounts**
- Chatward is now one server. You sign up with a sign-up code, a name and a password, and log in with name and password.

**Smaller fixes**
- Fixed the key-loading hang for test installs. Test installs import your keys from the installed app.
- The window fits your screen's usable area.
- Tab drag-and-drop is easier to land.

## Does the friend's server need updating?

Yes. The server must be updated to this version before the new features work. Older apps keep working against an older server, but the new features need it. Hand these to the friend's AI:

- **Everything (vault, Jellyfin, GIF library, one-server accounts, Spotify status):** update the server to the v1.0.0 `chatward-server.zip`.
- **GIF library:** new database table (created automatically) and an uploads folder. Steps are in `/mnt/project-files/gif-library/server-update-instructions.md`.
- **Spotify:** the server only passes along the "listening to" status. Steps are in `/mnt/project-files/spotify/server-handoff.md` and `/mnt/project-files/spotify/server-update-cover-progress.md`.
- **Voice:** LiveKit now uses one UDP port (7882) instead of 50000-50100. Router and firewall should allow 443/tcp, 7881/tcp and 7882/udp.
- **Jellyfin:** needs the Jellyfin server and API key configured on the server side.

## Known limits
- No TURN server, so a call may not connect for some home networks.
- No automatic nightly database backup yet.
- Real-Windows testing is still pending for the see-through LCARS window and for copying animated GIFs.
